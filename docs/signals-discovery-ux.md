# Signals discovery UX

Discovery is intentionally separate from the primary Signals feed.

- **Scan** answers: what currently looks actionable based on Collectish evidence?
- **Discovery** answers: what externally surfaced cards deserve a quick Scout check?
- **Feed** answers: what source-level claims and context have been captured?
- **Sources** answers: how are collectors configured and maintained?

MTGStocks Interests candidates are `discovery_only`. Appearance in the queue never changes a Scout grade. The screen leads with Collectish's own rating, allows A/B-first triage, exposes unrated cards as lookup candidates, and deep-links directly to Scout for investigation.

Mobile prioritizes card name, movement, and Scout assessment in two compact rows; source mechanics stay secondary. Desktop uses a denser triage list rather than large cards so the queue can be scanned quickly.
